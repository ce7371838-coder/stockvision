# StockVision

## Descripción

StockVision es una aplicación web desarrollada para administrar portafolios de inversión. Permite consultar acciones mediante la API de MarketData, realizar compras y ventas, administrar múltiples portafolios y visualizar el rendimiento de las inversiones.

## Tecnologías utilizadas

- React + Vite
- Node.js
- Express
- PostgreSQL
- MarketData.app API
- Nginx
- PM2
- Git y GitHub

## Funcionalidades

- Consulta de acciones.
- Cotización en tiempo real.
- Creación de portafolios.
- Compra de acciones.
- Venta de acciones.
- Cálculo de ganancias y pérdidas.
- Persistencia en PostgreSQL.
- Despliegue con HTTPS.

## Instalación

### Backend

```bash
cd backend
npm install
node server.js
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
