# Sprint 1

## Objetivo
Desarrollar la estructura base de StockVision.

## Actividades

- Crear el proyecto con React.
- Configurar Express.
- Configurar PostgreSQL.
- Diseñar la interfaz principal.
- Crear el catálogo de acciones.
- Conectar React con la API REST.

## Resultado

Se obtuvo una aplicación funcional con comunicación entre React, Express y PostgreSQL.
